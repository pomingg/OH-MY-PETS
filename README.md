## 💡 使用 「待實現圖表代碼模板.md」 的三個步驟

### 第一步：找到你要實現的圖表
```markdown
例如：1️⃣ Overview - 健康分數環形圖表
```

### 第二步：複製 HTML 容器
```html
<div class="section-head">
  <h2 class="section-title">四大領域健康分數</h2>
</div>
<div class="ring-row" id="healthRingRow"></div>
```

### 第三步：複製 JavaScript 代碼
```javascript
const ringData = [
  {label:'銷售', score:82, delta:'+3 較上季', up:true, color:'#E8A33D'},
  // ... 其他數據
];
// ... 圖表初始化代碼
```

### 第四步：粘貼到 index.html
- 在對應頁面找到容器位置
- 粘貼 HTML 和 JavaScript
- 刷新瀏覽器測試
