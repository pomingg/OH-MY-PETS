## 📋 第一部：五位長官的決策目標

### 1. **Sales 頁面** - 銷售總經理 王經理

#### 核心決策
1. **今月業績是否達成 90% 以上目標？**
   - 如未達成，是產品線問題還是市場問題？
   
2. **哪個產品線進度異常（< 80%）？**
   - 需要立即補貨、促銷還是客戶支援？
   
3. **週銷售有沒有連續下滑信號？**
   - 是否預示月度達成有風險？
   
4. **新客轉化率達標嗎？**
   - 長期增長動能是否充足？

#### 優先指標
- 🔴 P0：月度達成率（實時）、產品線進度（實時）
- 🟡 P1：週銷售趨勢、新客轉化率
- 🟢 P2：渠道分布、客戶集中度

#### 告警觸發
- 🔴 達成率 < 80% → 立即推送
- 🟡 達成率 80-90% → 下午 3 點彙總
- 🟡 週銷售環比 -15% → 黃區警告

---

### 2. **Production 頁面** - 廠長 李廠長

#### 核心決策
1. **現在有沒有停機或即將停機？**
   - 停機原因是什麼？需要多久修復？
   
2. **今日產量能否達成日均？**
   - 如不能，還差多少？應該如何補進度？
   
3. **品質狀況是否正常（良率 > 95%）？**
   - 如異常，是哪個班次/機台問題？
   
4. **各廠區稼動率有沒有明顯差異？**
   - 低效廠區的瓶頸是什麼？

#### 優先指標
- 🔴 P0：稼動率（實時 5min）、良率（實時）
- 🔴 P0：停機原因（實時）、停機時長（實時）
- 🟡 P1：班次稼動率分布、機台健康度
- 🟢 P2：日產量完成率、品質異常類型

#### 告警觸發
- 🔴 稼動率 < 60% → 立即推送 + 電話
- 🔴 停機時長 > 30 分鐘 → 立即推送
- 🔴 良率 < 90% → 立即推送
- 🟡 稼動率 60-75% → Slack 黃區警告

---

### 3. **HR 頁面** - HR 總監 陳總監

#### 核心決策
1. **各部門人力充足嗎（需求 vs 現有）？**
   - 缺人最嚴重的是哪個部門？要多久招到？
   
2. **本月流失率是否超警戒線（目標 < 5%）？**
   - 流失員工來自哪個部門？是否有共同原因？
   
3. **在崗率是否能支持生產計畫？**
   - 如不能，是請假多還是出差多？
   
4. **是否有部門的人力成本異常高？**
   - 需要優化調度還是加新酬？

#### 優先指標
- 🔴 P0：各部門缺員人數、在崗率
- 🟡 P1：月度流失率、流失部門分布
- 🟡 P1：招聘進度 vs 計畫、試用期轉正率
- 🟢 P2：部門人均成本、新員工培訓進度

#### 告警觸發
- 🔴 某部門缺員 > 10% → 立即推送
- 🟡 月流失率 > 3% → 黃區警告
- 🟡 在崗率 < 85% → 影響生產警告
- 🟢 招聘進度落後 15% 以上 → 趨勢監控

---

### 4. **Finance 頁面** - CFO 王 CFO

#### 核心決策
1. **現金流是否充足（最少需要 30 天流動資金）？**
   - 如不足，應該停分紅、加速收款還是延支付？
   
2. **本月毛利率是否達成目標（目標 38%）？**
   - 如未達，是成本增加還是定價下降？
   
3. **應收帳款有沒有老化（超 45 天是紅區）？**
   - 是否需要啟動催收或法律程序？
   
4. **負債比是否在安全範圍內（目標 < 50%）？**
   - 是否有空間進行新的融資或投資？

#### 優先指標
- 🔴 P0：現金餘額、現金流預報（未來 30 天）
- 🔴 P0：應收帳款老化（超 45 天金額）
- 🟡 P1：毛利率（vs 目標）、淨利率
- 🟡 P1：月度營收（vs 目標）、成本佔比
- 🟢 P2：負債比、流動比率

#### 告警觸發
- 🔴 現金 < 30 天流動資金 → 立即推送 CEO
- 🔴 應收超期客戶金額 > $200K → 立即催收
- 🟡 毛利率環比下降 > 2% → 成本異常警告
- 🟡 應收帳款老化 45-60 天 → 催收提醒

---

### 5. **Overview 頁面** - CEO / 營運長 林 CEO

#### 核心決策
1. **公司整體績效健康嗎？**
   - 4 個維度（銷售、生產、人力、財務）都達標？
   
2. **有沒有異常需要立即干預？**
   - 哪個部門、什麼問題、誰該負責？
   
3. **月度目標能否達成？**
   - 基於當前進度做風險評估和干預決策
   
4. **短期（未來 7 天）有沒有風險信號？**
   - 先發制人 vs 被動應對

#### 優先指標
- 🔴 P0：日度營收達成率、月度營收進度
- 🔴 P0：日度產量達成率、訂單交期達成率
- 🔴 P0：現金流健康度、應收帳款老化
- 🟡 P1：人力在崗率、人力缺員趨勢
- 🟡 P1：毛利率達成、成本超支預警
- 🟢 P2：各部門員工滿意度、品質趨勢

#### 告警觸發
- 🔴 任何部門進度 < 75% → 立即推送
- 🔴 現金流 < 30 天 → 立即推送
- 🟡 月度進度落後計畫 > 10% → 黃區警告
- 🟡 單個部門在崗率 < 80% → 協調警告
