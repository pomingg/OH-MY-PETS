🐛 常見問題

Q1: 啟動時看不到任何圖表？
A: 這是正常的。請稍候 2-3 秒，圖表會自動載入。如仍未顯示，請：
   1. 開啟瀏覽器控制台 (F12)
   2. 查看是否有紅色錯誤
   3. 檢查 Flask 後端是否運行 (http://127.0.0.1:5000)

Q2: Flask 後端無法連接？
A: 請確保：
   1. PostgreSQL 已啟動
   2. 資料庫存在 (oh_pets_company)
   3. 依賴已安裝 (pip install -r requirements.txt)
   4. 沒有其他程序佔用 5000 端口

Q3: 某些頁面的圖表未顯示？
A: 這可能是因為：
   1. 圖表初始化延遲，請稍候幾秒
   2. 瀏覽器暫存問題，按 Ctrl+Shift+Delete 清空暫存
   3. 檢查控制台錯誤信息

Q4: 如何修改圖表數據？
A: 有兩種方式：
   方式 1: 編輯 charts-integration.js 中的虛擬數據
   方式 2: 修改 backend.py 連接真實資料庫

Q5: 如何自定義圖表配色？
A: 編輯 index.html 中的 CSS 變量：
   :root {
     --sales: #E8A33D;
     --production: #35B0AE;
     --hr: #9B84E8;
     --finance: #4FBD84;
   }
